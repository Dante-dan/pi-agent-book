# 第二版书稿（施工中）

这里是配合 [π 工坊](https://pi.duanjl.com/) 重写的新版书稿。旧版 8 章仍在 [`../book/`](../book/)，全部写完之前两者并存。

## 和旧版有什么不同

- **游戏优先**：先去工坊里玩，卡住了或者想知道得更深，再来翻这里。每一站的正文同时就是游戏里的悬浮手册。
- **十站加一个专题**：章节对齐李博杰《[深入理解 AI Agent](https://github.com/bojieli/ai-agent-book)》的十章，另加沙盒专题。
- **每个概念答三问**：为什么会有它、它是什么、怎么用。
- **因果链来自原书**：每一站动笔前先通读原书对应章节，按它的推导顺序排任务，每个零件都由上一步留下的麻烦逼出来。十章的因果链整理在 [`../knowledge/`](../knowledge/)。
- **手册在游戏之后写**：先有能玩的关卡，再对照关卡写手册。手册解释的是你刚在屏幕上看到的那一幕。
