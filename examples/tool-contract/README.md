# 直接观察 Pi 工具契约

配合[第五章](../../book/05-tools.md)。程序直接调用 Pi 0.85.1 的真实工具函数，不使用模型或 API key，不加载用户扩展。所有文件位于自动创建的临时目录，结束后清理。

需要 Node.js 22.19.0 或以上。进入本目录：

```bash
npm ci --ignore-scripts
npm test
```

验证四件事：

1. `write` 原样写入美元符号、反引号和换行。
2. `read` 按行号与 limit 读取片段。
3. `edit` 接受本版本的 `edits` 数组并执行替换。
4. 默认读取 2005 行文件时，返回 2000 行范围的截断通知与 `offset=2001` 提示。

预期输出以 `PASS: literal write` 开头。这个实验证明工具函数在固定样例上的行为，不证明模型总能选择正确工具或参数，也不覆盖其他版本、图片或所有错误路径。
