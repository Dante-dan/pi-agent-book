# 延伸阅读

**简体中文** | [English](../../en/book/notes/README.md)

[返回目录](../../README.md)

正文沿着一条主线往下讲：从第一次运行 Pi，到循环、上下文、记忆、工具、扩展与持续进化。但知识本身是一张网，主线上的每个机制都会连到别的设计、别的产品和别的时代。这里收录的就是从正文分叉出去的内容：它们与当前问题相关，但如果在正文里展开，会打断主线。

每篇笔记都可以单独阅读。开头注明它从正文哪一处分叉出来、需要哪些前置概念、读完可以接着读什么；正文里对应的位置也有一条“延伸阅读”链接指回来。

## 分叉怎样处理

写作途中遇到分叉时，按它与主线的关系选择处理方式：

| 情况 | 处理方式 |
| --- | --- |
| 不理解它，就读不懂当前这一段 | 在正文中就地展开 |
| 有助于理解，但会打断主线 | 写成笔记，正文用一句结论加“延伸阅读”链接 |
| 本身就是一条需要多节展开的主线 | 讨论后作为新的章节 |
| 正文其他章节已经讲过 | 直接链接到那一节，不要重讲 |

笔记的写法与正文一致：先给具体处境，结论有出处，Pi 的机制仍然链接到固定提交的源码。不同的是，笔记可以讨论 Pi 之外的系统、历史和争论，但应区分哪些是已核实的事实，哪些是观点。
