# 第 6 章 交互：观察与动作空间的扩展

行号均指 `book/chapter6.md`（共 776 行，已从头读到尾）。本章结构是“一个总论 + 四个并列场景（异步 → 语音 → Computer Use → 机器人）”。场景之间只有两处原书明确写了衔接（异步→语音 L305，语音→Computer Use L462），Computer Use→机器人没有衔接句，只在小结 L738 里并列，下面如实标注。

## 一句话主旨
前五章的 Agent 与世界是“轮流”交互、世界在 Agent 思考时静止；本章挑战这个前提，沿**模态**和**触发时机**两根轴扩展观察与动作空间，四个场景（异步事件、语音、Computer Use、机器人）共享同一条“感知 → 判断 → 行动 → 观察反馈 → 继续/修正/重试/停止/重规划”的闭环骨架和同一组原语（唤醒、安全点、取消、抢占、快慢分离）（§本章小结 L738–751）。

## 起点问题
接第一章的论断：模型固定时，最主要的系统工程手段是重新定义观察空间与动作空间（L3）。第二至五章扩展的是空间的**内容**（上下文、记忆、工具、代码）；但这些章节默认“用户说完 → Agent 想/调工具 → 回话，期间世界静止”。真实环境不会等：邮件在思考时到达，用户说到一半被插话，页面在两帧之间变了，杯子在机械臂伸手途中被碰倒（§模态与触发时机的扩展 L20）。缺口：回合制是接口约定，不是环境性质，需要把“模态”和“时机”也扩展开（L12–18 的 3×2 表）。

## 因果链
本章分四段链：A 异步事件（节点 1–15）→ B 语音（16–21）→ C Computer Use（22–26）→ D 机器人（27–33）。A→B、B→C 原书有明确衔接；C→D 无衔接，是并列。每段内部首尾相接。

## 概念清单
- **回合制是约定非环境性质**｜前五章默认世界在思考时静止，真实环境不等人｜接口层的同步轮次组织（提问后回答、工具调用后补齐结果），不是环境本身的特性｜用“模态 × 时机”两轴重新审视观察/动作空间｜L3、L12–26
- **事件驱动异步架构**｜同步柜台无法兼顾后台任务、紧急事件、中断恢复｜所有输入输出统一为事件流，新事件到达自动触发处理，而不是轮询｜需先确认模型/API 的消息时序支持，再选原生或兼容层｜L37–47
- **Heartbeat / Cron / Hooks / Channel**（OpenClaw、PineClaw）｜Cron/Heartbeat 只是时间驱动，第三方事件无即时通道｜Heartbeat 每 N 分钟唤醒；Cron 按表达式；Hooks 响应框架内部生命周期；Channel 把外部事件实时推给 Agent｜OTP/三方通话类需要几秒内响应的场景必须用 Channel｜L51–69
- **事件触发工具**（`set_timer` / `monitor_shell` / `connect_channel`）｜没有它们 Agent 只能循环到出结果后等用户｜分别处理物理时间、后台命令输出、外部推送｜设计触发条件与过滤、载荷带足上下文｜L75–83
- **用户沟通工具与召回**｜assistant 消息直发用户的范式不支持用户不在线、异步沟通｜专门工具发消息，可带附件、按紧急度选渠道｜多渠道综合来源/状态/内容/偏好选择｜L87–97

- **长程规划 + 技能原语 + 五工具**｜整句目标不能直接交给动作模型｜拆成可检查技能节点｜单次一件事、固定范围、超时、执行后重观察｜L638–662
- **VLA 与动作分块**｜规划不决定连续动作｜观察+指令→动作；一次生成一小段高频回放｜平滑性与反应速度取舍｜L664–676
- **sim2real（域随机化式的变化覆盖）**｜背景/光照/相机/摩擦/噪声/延迟不同｜训练时主动扩大画面变化范围｜真机仍需标定、测试、安全闭环｜L726–734

## 递进能力
- 按获得顺序：
  1. 能被外部事件唤醒（定时器/监控/外部通道）；能主动、多渠道联系用户；以独立虚拟身份在隔离环境中行动
  2. 能按紧急度在取消/队列/并行三种策略间选择；能在同步接口下用占位符处理悬空工具调用；用任务句柄表达异步工具；对批量事件不漏答
  3. （原生异步模型）工具运行时继续独立工作，并接受回合中途引导
  4. 边听边说：流式感知、全双工、前台快模型+后台慢模型；用控制标记驱动更像人的语音
  5. 用截图+动作三类工具操作 GUI；能选 DOM 索引/SoM/坐标预测；能处理分辨率缩放；能感知两帧之间的变化（AOI）；能在行动前预测后果（世界模型）
  6. 能在受约束的技能工具上控制机器人：规划分解、逐步观察确认、动作分块、世界模型预测、跨环境泛化
- 依赖前面章节：第一章五类工具与观察/动作空间论断（L3、L31）；第四章的感知/执行/协作工具与《Her》Samantha 例（L31、L103）；第二至五章的上下文/轨迹/记忆（轨迹追加事件、占位符、状态栏标记都在轨迹层面操作）；ReAct 原生循环（L87）。
- 伏笔：第七章评估（AndroidWorld 基准 L577；并要求评估“模型是否理解变化、系统是否按变化执行”L297）；第八章后训练（异步环境训练 L297）；第九章持续进化闭环；第十章多 Agent 协作（`agent.input`/`agent.interrupt` 事件 L161–163）（L753）。

## 关卡候选
事故均构造成脚本化、可确定复现；不依赖模型本来就知道的常识（用虚构数据，答案只存在于工具返回或事件里）。

|---|---|---|---|
| 代接银行电话 | 客服在通话中要求 60 秒内给出 OTP；Agent 每 5 分钟 Heartbeat 才检查一次，用户收到通知时通话已被挂断，任务失败 | 外部事件通道（connect_channel）、用户沟通工具（带推送） | 3、4、5 |
| 搜索联系人时被插话 | 严格协议校验器：用户在 `search_contacts` 未返回时插话“先查明天天气”，轨迹出现无配对 tool_result 的 tool_call，请求被拒绝，Agent 当场卡死 | 事件循环 + 占位符 tool result（打断时补占位符，结果后到再追加） | 7、9、11 |
| 占位符里的幽灵邮箱 | 占位符已写入后，Agent 在真实结果未到前给用户答复；联系人邮箱是虚构的（只出现在后到的工具结果里），Agent 编出了一个 | 任务句柄（`initiate_*` 返回任务 ID 与状态）+ 评估检查“是否使用未到达数据” | 11、12 |

## 容易讲错的地方
- 回合制不是环境的性质，而是接口约定（L20）。不要把“只能同步”讲成 LLM 的固有限制；作者明确说占位符问题“来自所选协议与模型组合，并非所有 LLM 都必须遵循”（L202），也不能仅凭一次失败把原因归结为某个未公开的训练过程（L226）。
- 不能因为代码用了 `asyncio` 就认定模型具备原生异步（L43）；原生异步只解决“消息能否到达”，可靠性（结果归属、任务恢复、综合多条更新）仍要单独检查（L289–297）。
- OpenClaw 的“自主”只靠 Cron/Heartbeat 这类时间驱动；Gateway 对内置渠道是推送，但第三方事件缺通道，这是作者指出的“真正的短板”（L57–59）。主动服务 = 定时检查 + 事件主动通知（L71）。
- 取消式的本质是“提前制造安全点”，并行式是“另起循环不必等主循环安全点”（L121、L153）；接收一条“停止”消息不会撤销已发生的动作，取消要执行器配合（L119）。未完成工具结果用显式占位符，不能伪造成功（L167）。
- 作者建议用轻量分类 LLM 做事件路由，认为硬编码规则有局限（L165）。
- 级联/Omni/全双工是取舍不是新旧替代（L315）；Omni 仍依赖 VAD 轮次（L395）；实验 6-6 测的是音频信息是否保留，不是“边想边说”（L402）。
- 快慢思考三个方案是设计取舍，不是线性迭代（L418）；快慢分离不只是延迟妥协，而是承接慢模型迭代红利的模块化选择，τ³-Voice 第一名说明解耦不天然落后于端到端（L442–444）。“端到端”有两层含义，两条轴独立（L448）。
- Computer Use 难点不只是在截图上答对，而是每步之后重新确认现实是否仍符合计划（L471）；Anthropic 动作空间是参考设计，不是供应商私有协议（L481）。
- 视觉定位：结构化信息可得优先 DOM/无障碍树，不可得时 SoM 与坐标预测二选一，两者在小元素与密集界面精度都有差距（L540）；SoM 原本是纯视觉方法，DOM 索引是它在 Web 上的结构化实现（L504–508）；DOM 索引方案不省 token（L525）。
- Computer Use 该重新设计的是“观察接口”，不是“动作接口”（L552）；观察接口不消除规划延迟（L558）；世界模型要预测的是可检查的状态差异，不是逼真的未来截图（L568）。
- 移动端：真正卡住的是生态壁垒而非技术差异，根因是商业模式冲突（L579–583）。
- 机器人：“硬件不是瓶颈，算法才是”仅限本桌面任务（L604–606）；模型不应直接输出任意关节角（L636）；遥操作既是数据收集也是“固定硬件、替换操作者”的诊断（L608）。
- 动作分块不是无代价的加速（L676）；世界模型的预测只能帮助选择，不能代替验收，真实观察才是最终事实（L714）；会生成视频不等于能指导机器人动作（L716）。
- 实验 6-13 并不证明小型模拟世界模型等同真实物理模型，仿真稳定也不能推出真机成功（L724、L728）；实验 6-10/6-12 是真机实验，6-11/6-13/6-14 是模拟，结果必须分开报告（L587）。
- 小结：四个场景共享的骨架与原语（唤醒、安全点、取消、抢占、快慢分离）（L738–751）；思考题 12（L776）再次点出同一组原语在不同时间尺度上的实现差异。
