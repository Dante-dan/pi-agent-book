# 第 8 章 模型后训练

> 出处行号均指 `book/chapter8.md`（全文 879 行，已从头读到尾）。本章是全书里最“偏训练”的一章：游戏里玩家是 Harness 设计师，本章的零件多半不是“装进 Harness 的代码”，而是“训练前后必须在 Harness/训练管线里放的探针、门禁、校验器、隔离规则”。关卡设计请按这个思路转译。

## 一句话主旨
Mid-training、SFT、RL 不是三档“微调力度”，而是分别补**底座（知识与基础能力）、协议（格式与流程）、策略（概率质量的重新分配）**；整章贯穿一句话：模型学到什么取决于训练信号，而信号质量主要由**数据和环境**决定，不是算法（§引言 L16–19；§本章小结 L822–826）。

## 起点问题
接第七章结尾：评估体系与仿真环境是后训练的两块基石（评估环境=练习场，评估指标=训练目标）（§引言 L3）。前七章的 Agent = LLM + 上下文 + 工具，都在“不动权重”的前提下改进；本章问：**当 prompt、工具、上下文都不够，难以由外部规则完整表达的能力，怎么写进参数？** 以及更实际的：缺的到底是底座、协议还是策略，不要一律归因成“需要 RL”（§何时选择 L388）。

## 概念清单
- **预训练 / NTP**（Pre-training, Next Token Prediction）｜要让模型有语言、世界知识、基本推理｜给前文预测下一个 token，输出本质是概率分布，所有后续阶段都是在“调整这个分布”，区别只在“想要什么、用什么信号定义想要”｜§预训练 L41–47
- **Mid-training**（CPT/DAPT/TAPT）｜通用预训练没覆盖目标语言/领域/能力，跳过它直接 SFT/RL 补不上｜继续做下一 token 预测、全 token 算损失、混保留数据；解决知识缺口与基础能力缺口｜先从失败分布反推数据，双重回放，多维门禁；动态事实走 RAG｜L49–53, L276–304
- **SFT / loss masking**｜预训练后模型不会遵循“被提问就回答”的协议｜同一损失函数，数据换成输入—输出对，仅在回答 token 上回传梯度｜固化格式/风格/流程，不灌大量事实；数千条高质量即可；噪声会被忠实写入参数｜L55–64, L318–328
- **LoRA**｜全参微调显存贵｜冻结原权重，旁挂低秩补丁，参数约 1%–5%；遗忘风险较低｜应用到所有主要权重矩阵（尤其 MLP，只加注意力会掉点）；最优学习率约为全参的 10 倍；SFT 用 rank 64–256，RL 用 8–32 甚至 1；可多 adapter 多租户｜L66
- **pass@k**｜判断 RL 有没有东西可放大｜$1-(1-p)^k$，在留出任务上以与训练相近的温度采样｜pass@1 低但 pass@k 随 k 明显上升→正确策略在分布里，可 RL；pass@k 仍近 0→先补底座。等 $1/p$ 的偶然成功没有实际意义｜L74–82
- **GRPO / PPO / DPO**｜需要不同的“拿谁比较”｜GRPO 组内相对优势，不要价值模型；PPO 带价值网络和概率比裁剪（裁剪抑制大步更新，不是硬约束）；DPO 直接学离线偏好对｜本章案例的算法分配：AdaptThink 自定义约束目标；GeneralPoints/V-IRL/ReTool 用 PPO；SimpleVLA-RL/RLVP 用 GRPO｜L414, L500–502
- **Rollout / step**｜RL 的最小“采样单元”与“迭代单元”｜一次 rollout=一次完整的读码→改文件→跑测试→提交；一个 step=采样、算奖励/优势、梯度更新的一个闭环；日志里的 `step` 定义要先确认｜L486, L496
- **Online vs On-policy**｜容易混用｜Online 只说数据在训练中不断产生；On-policy 要求行为策略 μ≈当前策略 π_θ。异步落后几个 checkpoint 就已带 off-policy 成分｜重要性比率 $\rho_t=\pi_\theta/\mu$，新鲜 on-policy 更新前应为 1｜L506–515
- **训练—推理数值失配**｜同权重也会因精度/归约顺序/批大小/kernel 不同而 log prob 不同｜更新前 ρ 就偏离 1，on-policy 悄悄变 off-policy，引发 ρ 尖峰、大量 token 被裁剪、响应长度突变、奖励和熵一起坍塌｜更新前对比 log prob 并监控；对齐精度和并行布局；做不到就显式按 off-policy 修正｜L519–528
- **RLVR / 可验证奖励**｜规则越确定，奖励越便宜、可复现、难钻空子｜用测试、数据库断言、状态差异、格式检查直接判结果｜数学答案、代码测试、结构化工具调用从二元结果奖励开始｜L616
- **ORM / PRM**｜稀疏结果难做信用分配，过程奖励又限制路径｜ORM 只在 episode 结束判；PRM 在中间步给反馈（《Let's Verify Step by Step》）｜先用结果奖励建基线，再只为真正可验证的中间事件加过程信号；V-IRL（密集）vs SimpleVLA-RL（稀疏）对照｜L626–632
- **Reward hacking vs Reward seeking**｜“通过了 grader”不等于“任务完成”｜前者钻规则/实现漏洞拿高分；后者模型猜评判器会看什么，自设过于简单的检查刚好通过就早停，交付物只满足代理指标｜判定交给模型写不了的隐藏测试/状态断言/外部终止钩子｜L622, L626
- **RLVP**｜结果奖励看不见路径违规，且在全败/全胜组零方差｜奖励结果、惩罚路径，$R=O+\beta\Phi$，只对确定性可验证的“结果中性约束”动作作用｜只惩罚具体动作，结果奖励保留，惩罚配可达合规路径；不能替代对语义意图、交付完整性、早停的独立检查｜L646–668
- **拒绝采样 / RFT**｜教师或自己采样的轨迹有错的，学生会照样模仿｜生成候选→验证过滤→只留正确轨迹→做 SFT；介于 SFT 与 RL 之间，不训奖励模型、不做策略梯度｜可验证任务上性价比高｜L363, L372
- **Prompt 蒸馏**｜长系统提示和思考 token 拉高延迟与费用｜只保留用户输入与最终结论，教师在完整提示+思考模式下出答案，学生学“直接给结论”；大到小、思考到非思考两个维度（后者 20–30 倍响应速度）｜继承教师边界；教师若靠工具保证正确，单纯输出蒸馏会丢鲁棒性；产品形态稳定后再做，探索期保留显式提示｜实验 8-8 L345–349
- **CoT 蒸馏**｜最务实的跟随者策略｜转移教师完整思考轨迹，同参数量可恢复教师 70%–80% 能力；采集→规则过滤→SFT→对比评估｜选开源教师（闭源有“思维围墙”：CoT 被改写/摘要）；作者强观点：绝大多数人没必要蒸馏闭源 CoT，开源 SOTA 够当 200B 及以下学生的教师｜实验 8-9 L351–365
- **On-Policy Distillation**｜RL 稀疏、SFT 只覆盖教师状态｜学生采样，教师在学生前缀上给逐 token 分布，最小化 KL｜教师必须明显更强；环境要够真实｜L680–709
- **OPSD**｜没有更强教师｜同一模型，教师版看特权信息｜特权信息仅训练侧；加保留正则防丢思考风格｜L713–731
- **环境保真度 / 模型扮演环境**｜环境失真→“应试策略”｜可重置、可并行、可复现；造不出时用 LLM 合成工具返回值或仿真动态｜混合真实交互定期校准模拟器偏差｜L536–552
- **信用分配**｜多轮奖励延迟｜PPO 价值网络/turn-level 优势，GRPO 轨迹级优势均摊到 token｜多轮常 γ=1；长轨迹注意信号稀释｜L572, L632
- **反馈 token 屏蔽**｜环境返回的 token 不是策略生成的｜计算策略梯度只对模型自己的思考与工具调用参数回传梯度｜否则模型学成预测沙盒输出｜L592
- **边界集 vs 保留集**（第一章命名的模式）｜只修“未完成时的错误行为”会过度矫正｜边界集看是否继续验证，保留集看已完成时是否正常收尾｜两者缺一不可，另抽查通用能力确认 LoRA 补丁没有伤到其他能力｜L754
- **灾难性遗忘与泛化下降**｜每个阶段都会遗忘/过拟合｜Mid-training 遗忘通用能力，SFT 过拟合示范，RL 过拟合奖励与任务分布｜三者都需要独立保留集和早停｜L808, L310

| 3. “过早结束”：Coding Agent 宣称“已完成”但隐藏测试失败 | 模型文字上说“测试全过”，隐藏验收测试 3/4 未过；若只奖励“宣称完成”，下一轮它更会说漂亮话 | 隐藏验收测试（模型写不了的验证器，读真实文件）；再追加：保留集防止“永远不敢收尾”的过度矫正（第二个事故：已完成任务也无限验证、延迟爆表） | #12, #16a |
| 4. 路径违规：结果奖励满分但 Agent 改了测试文件/跳过身份验证 | 结果奖励 1.0，审计面板显示违规动作均值 3.71 次/任务；全胜组里奖励方差为 0、策略学不到“该怎么办成” | RLVP 路径惩罚规则（只罚具体动作）+ 保留结果奖励 + 配可达合规路径；故意加一版“只罚不留结果奖励”让模型学会什么都不做作为对照 | #13 |
| 5. `old_string` 不匹配归因：编辑工具持续失败 | 同一个文件带反斜杠的行永远 edit 失败；玩家要对 8 层链路逐层 diff（文件字节→工具返回→Harness 序列化→上下文→模型输出→解码→JSON 解析→匹配），发现 Harness 序列化层把 `\` 转义了一次，才不该判给模型 | 逐层字节 diff 探针（归因链），归因给 Harness 后修 Harness，而不是去训练模型 | #16c |
| 6. 采样与训练 log prob 对不上：on-policy 训练突然崩 | 更新前 $\rho_t$ 最大值 54.6、被裁剪比例飙升、响应长度突变、奖励和熵一起塌；权重明明同步了 | 更新前 sampler/trainer log prob 对比监控（均值/分位/最大/近似 KL/clip 比例）；同步 tokenizer/chat template/LoRA/revision | #8 |
| 7. 模拟器过于仁慈：训练用的模拟客服永远耐心、模拟搜索引擎从不返回垃圾 | 训练曲线漂亮，上线第一天遇到催促/噪声用户成功率腰斩 | 混合真实交互、定期校准模拟器、噪声课程（先好后渐差，如 ZeroSearch） | #9, #10 |
| 8. 训练/评估泄漏：用评估集任务做 RL，评估分数虚高 | 同一任务既训又测，评估通过率 98%，换一批同模板新任务掉到 55% | 训练/评估隔离（共享生成器和验证器、不共享任务；隐藏测试留验证器侧） | #9 |

## 容易讲错的地方
- **“SFT 记忆，RL 泛化”不是普适规律**，只是 GeneralPoints 和 V-IRL 受控设置下的倾向；数据多样、正则得当时 SFT 也能泛化，奖励/环境有偏时 RL 也会过拟合；原书多次重申（L18, L91, L101, L478, L822）。
- **“必须先 SFT 再 RL”只在格式/基本行为尚未建立时成立**：Llama-3.2-Vision-11B 在严格结构化输出设置下直接 RL 失败，但足够强、已有非零成功率的基模可以跳过 SFT（DeepSeek-R1-Zero）；R1 后来的冷启动 SFT 主要为了可读性与语言一致性，不是注入任务知识（L84, L476）。
- **SFT 不是新方法**，数学上和预训练是同一个任务，唯一实质区别是 loss masking 和数据（L57–60）。
- **SFT 不适合当知识库灌入工具**；大量稳定知识用 Mid-training，需更新/引用/权限控制/删除的事实用 RAG；但 Mid-training 降低了领域文本 loss 并不保证问答式取得出，要接 SFT（L53, L285, L802）。
- **RL 不擅长从全零奖励中凭空创造能力**，擅长把“已有但概率低”的行为推高；`pass@k` 近 0 时加 PPO/GRPO 只会烧采样预算（L82, L406, L805）。
- **同权重≠on-policy**：同步权重后 sampler 与 trainer 的 log prob 仍可能因数值差异不同；PPO clipping 不能无损兜底，不是“有 clip 就安全”（L515, L519–527）。
- **Online ≠ On-policy**（L506）。
- **LoRA 并非免疫遗忘**（思考题 1 L866）；最优学习率约为全参的 10 倍这个迁移规则对 SFT、RL 都成立（L66）。
- **作者的强观点**：数据和环境比算法更重要（很多场景只要前两类数据到位甚至不需要 RL，L19）；“先验 > 环境 > 算法”（L231）；高保真环境常比训练本身更贵更难（L539）；在动手调算法前先问“仿真环境真的像真实世界吗”（L542）；绝大多数后训练者无需蒸馏闭源 CoT（L361）；当前 RL 主要瓶颈是样本效率与分布一致性（L826）。
- **不要为了“奖励更丰富”堆不可验证的维度**，每个维度都是一种被钻空子的可能（L642）；**奖励不能依赖模型自己的声明**，否则模型学会“口头声称去验证”（L628, L762）。
- **RLVP 的边界**：只针对可机器判定的“结果中性约束”，不能替代对语义意图/交付完整性/早停的独立检查；实验数字来自可控代理环境，不能直接外推线上（L646, L668）。
- **边界集+保留集缺一不可**：只盯“未完成时继续验证”会训出永远不敢收尾的模型（L754）。
- **OPSD 不会造知识**；On-Policy Distillation 也不是“从零创造能力”，基模连领域概念都没有仍要先 Mid-training/冷启动（L690, L731）。
- **80.1% 不能全算模型的锅**：tokenizer 无损 round-trip 上限也是 80.1%，训练前必须逐层归因（L794）。
- **AdaptThink 的数字不能夸大**：只能说数据集汇总层面有与难度一致的路由信号，不能称“逐题完美难度感知”，也不能声称准确率普遍提升；训练在 step 410 崩溃，未完成配置的 3140 steps（L456–458）。
- **OpenVLA 是模仿学习（SFT 性质），不是 RL**；真正把 RL 引入这类 VLA 的是 SimpleVLA-RL（L225）。
- **模型“行动阈值”不要拟人化**（“谨慎/有直觉”），它是参数中的策略在估计“多读一个文件”和“提交并验证”哪个预期价值更高；实验只能证明模型侧存在差异，不能断言具体私有算法（L110）。
